🎓 Déploiement — Client AMED

Site web : amed-app.tn

Procédure complète de A à Z

1

Préparer la copie locale (sur votre PC)

1.1 — Copier le dossier de référence

cd "C:\Users\Sahnoun HAWALA\Desktop"
robocopy "ecole-app" "amed-app" /E /XD node_modules .next .git

1.2 — Nettoyer les anciens fichiers

cd "amed-app"
Remove-Item ".env" -Force -ErrorAction SilentlyContinue
Remove-Item ".env.local" -Force -ErrorAction SilentlyContinue
Remove-Item ".vercel" -Recurse -Force -ErrorAction SilentlyContinue
Remove-Item ".next" -Recurse -Force -ErrorAction SilentlyContinue

1.3 — Installer les dépendances

npm install
2

Créer la base de données (Neon)

  1. Allez sur console.neon.tech → New Project.
  2. Nommez-le amed-app.
  3. Région : Frankfurt.
  4. Cliquez sur Create.
  5. Cliquez sur Connect → copiez la chaîne de connexion Pooled.
💡 Format de l'URL : postgresql://neondb_owner:MOT_DE_PASSE@ep-xxx-pooler.region.aws.neon.tech/neondb?sslmode=require
3

Générer la clé de chiffrement (unique pour AMED)

node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"

Copiez le résultat (ex: xY3kL9...==). Ne la perdez pas.

4

Créer le fichier .env local

Créez le fichier .env dans amed-app/ avec ces valeurs :

CONFIG_ENCRYPTION_KEY="COLLER_LA_CLE_GENEREE"
NEXT_PUBLIC_APP_URL="http://localhost:3000"
DATABASE_URL="COLLER_URL_NEON_POOLED"
BOOTSTRAP_DATABASE_URL="COLLER_URL_NEON_POOLED"
BOOTSTRAP_ADMIN_EMAIL="admin@amed-app.tn"
BOOTSTRAP_ADMIN_PASSWORD="Admin123!"
5

Initialiser la base et tester en local

5.1 — Appliquer les migrations

npx prisma migrate deploy

5.2 — Bootstrap (crée la config et le compte admin)

npm run bootstrap

5.3 — Lancer en local

npm run dev

Connectez-vous sur http://localhost:3000 avec admin@amed-app.tn / Admin123!.

6

Déployer sur Vercel (nouveau projet)

  1. Allez sur vercel.com → Add New Project.
  2. Importez le dépôt elec-connect/ecole-app (le même GitHub pour tous les clients).
  3. Nom du projet : amed-app.
  4. Ajoutez les variables d'environnement :
NomValeur
DATABASE_URLL'URL Neon Pooled
CONFIG_ENCRYPTION_KEYLa clé générée à l'étape 3
NEXT_PUBLIC_APP_URLhttps://www.amed-app.tn
CRON_SECRETamed-cron-2026 (valeur temporaire)
  1. Cliquez sur Deploy.
7

Configurer le domaine amed-app.tn (OVH + Vercel)

7.1 — Sur Vercel : Projet amed-app → Settings → Domains → ajoutez amed-app.tn et www.amed-app.tn.

7.2 — Sur OVH : Allez dans Web Cloud → Domaines → amed-app.tn → Zone DNS.

7.3 — Ajoutez les enregistrements fournis par Vercel :

TypeNomValeur
A@L'IP fournie par Vercel (ex: 76.76.21.21)
CNAMEwwwcname.vercel-dns.com

7.4 — Attendez la propagation (quelques minutes à 24h). Vercel générera automatiquement le certificat SSL.

⚠️ Ne touchez pas aux enregistrements MX existants si vous avez des emails OVH sur ce domaine.
8

Configurer Resend pour les emails

8.1 — Sur Resend : Ajoutez le domaine amed-app.tn.

8.2 — Sur OVH : Ajoutez les 4 enregistrements DNS fournis par Resend :

  • 1 DKIM (TXT)
  • 2 SPF (CNAME)
  • 1 DMARC (TXT)
⚠️ Ne touchez pas aux MX existants. Resend ne demande que des TXT et CNAME.

8.3 — Vérifiez le domaine dans Resend (statut « Verified »).

8.4 — Créez une clé API Resend (re_...).

8.5 — Dans l'application AMED : Connectez-vous en SUPER_ADMIN → /admin/configuration → déverrouillez → section Resend :

  • Collez la clé API re_...
  • Email expéditeur : AMED <contact@amed-app.tn>
  • Enregistrez.
9

Configuration finale dans l'application

  1. Allez sur /admin/configuration :
    • Nom établissement : AMED
    • Année scolaire : 2025-2026
    • Logo : uploadez le logo d'AMED.
  2. Allez sur /admin/classes → ⚡ Générer les 5 classes par niveau (crée les 65 classes).
  3. Allez sur /admin/matieres → créez les matières.
  4. Allez sur /admin/utilisateurs → créez les professeurs, puis les élèves.
10

Livrer l'application au client

10.1 — Désactivez la protection Vercel (si activée) : Settings → Deployment Protection → Standard Protection.

10.2 — Donnez au client :

  • L'URL : https://www.amed-app.tn
  • Identifiant admin : admin@amed-app.tn
  • Mot de passe : Admin123! (à changer après la 1ère connexion)

10.3 — Pour l'icône sur le bureau : Le client ouvre le site dans Chrome → clique sur ⊕ Installer (PWA) → l'icône AMED apparaît sur le bureau.
